# OwnTV 0.2.3

[Baixar APK](https://github.com/elizandropacheco/OwnTV/releases/download/v0.2.3/OwnTV-0.2.3.apk) · [Notas da versão](RELEASE_NOTES.md)

O APK é gerado nesta pasta por `./scripts/build-release.sh`; o binário público é hospedado no link acima. Os arquivos ao lado registram a entrega:

- `SHA256SUMS.txt`: integridade do APK.
- `build-info.json`: commit de origem, versão, assinatura e verificações.
- `security-audit.json`: escopo e resultados da revisão.
- `dependency-inventory.json`: coordenadas das dependências resolvidas consultadas.

Código aberto na árvore do projeto, sem pacote de fontes ou logos editáveis em ZIP. Veja [como compilar e assinar](../../docs/BUILDING.md).
