# OwnTV Android 0.2.4

Botão **Entradas** sempre disponível no rodapé da Home, abrindo o seletor existente de entradas físicas da TV.

- Build release e lint aprovados; versão 0.2.4, código 105, APK não depurável.
- Assinatura local compatível com a entrega 0.2.3; confira o certificado no build-info.json.
- Sem teste físico desta revisão na TCL durante a rodada LG; recursos anteriores mantêm os registros anteriores.
- APK, SHA256SUMS.txt e build-info.json em [GitHub Releases](https://github.com/elizandropacheco/OwnTV/releases/tag/v0.2.4).

Veja [compilação](../../docs/BUILDING.md) e [instalação](../../docs/INSTALLATION.pt-BR.md). O piloto LG é um pacote separado e não executa este APK.
